✨ 功能特性

  • 基于 URL 的路由跳转
  • 支持浏览器前进/后退按钮
  • 每个页面都有独立的 URL
  • 支持页面书签和分享
  • 所有子页面都有"返回首页"按钮
  • 切换路由时自动滚动到顶部
  • 组件懒加载，优化性能

🧪 测试清单

  • 点击"← 返回首页"能回到首页
  • 点击浏览器后退按钮能返回
  • URL 栏显示正确的路由
  • 刷新页面路由保持不变
  • 可以直接访问 http://localhost:5000/history

💻 代码示例

导航到其他页面:
import { useRouter } from 'vue-router' const router = useRouter() // 编程式导航 router.push('/generator') router.push('/history') router.push(`/history/${id}`)
返回首页:
// 在组件模板中 <button @click="$router.push('/')"> ← 返回首页 </button> // 或使用浏览器后退 <button @click="$router.back()"> ← 返回 </button>
