# 配置预设模板（完整版）实施计划

**目标**: 配置预设模板 + 管理界面，一键生成常见练习场景

**功能**:
- 内置 4-8 个预设模板
- 预设选择器 UI（Tab 或下拉）
- 点击预设自动填充配置并生成
- 支持用户保存自定义预设
- 预设管理（增删改排序）

**工时**: ~9.5 小时

---

## 任务清单

### Task 1: 创建预设配置常 (~15 分钟)

**文件**: `src/constants/presets.js`

**步骤**:
1. 定义 3 个预设配置
2. 导出预设列表

**验收**: 预设配置格式正确，可被导入使用

### Task 2: 添加预设按钮到 ActionBar (~30 分钟)

**文件**: `src/components/ActionBar.vue`

**步骤**:
1. 添加 `presets` prop
2. 渲染预设按钮
3. 点击触发 `@apply-preset` 事件

**验收**: 3 个预设按钮正常显示

### Task 3: 实现预设应用逻辑 (~1 小时)

**文件**: `src/App.vue`

**步骤**:
1. 导入预设配置
2. 实现 `applyPreset(preset)` 函数
3. 应用预设后自动生成题目
4. 显示 Toast 反馈

**验收**: 点击预设按钮后自动填充配置并生成题目

### Task 4: 样式优化 (~30 分钟)

**文件**: `src/components/ActionBar.vue`

**步骤**:
1. 预设按钮样式（次要按钮风格）
2. 移动端适配
3. 按钮间距和布局

**验收**: 按钮在桌面和移动端都正常显示

### Task 5: 单元测试 (~1 小时)

**文件**: `src/constants/presets.test.js`

**步骤**:
1. 测试预设配置结构

**验收**: 测试全部通过

### Task 6: 集成测试和文档 (~1.5 小时)

**步骤**:
1. 手动测试所有预设按钮
2. 验证配置正确应用
