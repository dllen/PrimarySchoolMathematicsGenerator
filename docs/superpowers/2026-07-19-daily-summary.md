## ✅ 完成版本

### v1.1.0 - 易用性与可靠性优化

#### 核心功能

1. **配置向导 (ConfigWizard)**
   - 3 步配置流程（基础 → 题型 → 高级）
   - localStorage 持久化
   - 进度指示器
   - 默认收起高级设置

2. **Toast 通知系统**
   - 4 种类型：success/error/warning/info
   - 3 秒自动消失
   - 点击手动关闭
   - 全局响应式管理

3. **一键重生成**
   - 记住上次配置
   - 刷新后显示提示条
   - 一键应用生成

4. **错误处理增强**
   - IndexedDB 错误 Toast 提示
   - 生成超时保护（5 秒）
   - 导出失败降级（PDF → 图片）
   - 删除历史确认对话框

5. **配置预设（完整版）**
   - 6 个内置预设
   - 预设选择器
   - 预设管理器
   - 自定义预设（增删改）

6. **预设编辑功能**
   - 可视化配置编辑器
   - 年级/学期/题数/难度/题型
   - 图标预览

7. **预设导入/导出**
   - 导出为 JSON 文件
   - 从文件导入
   - 格式验证
   - 错误处理

8. **拖拽排序**
   - HTML5 Drag & Drop
   - 自动保存
   - 视觉反馈
