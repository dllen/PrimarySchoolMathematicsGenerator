## ✅ 基础功能测试

### 1. 配置向导

- [ ] **Step 1 - 基础配置**
  - [ ] 年级按钮可以点击选择（1-6年级）
  - [ ] 学期按钮可以切换（上册/下册）
  - [ ] 题目数量滑块可以拖动（10-100）
  - [ ] 下一步按钮可用

- [ ] **Step 2 - 题型选择**
  - [ ] 算术题/应用题/奥数题可以多选
  - [ ] 选择算术题后显示"算术题类型"下拉框
  - [ ] 可以选择"求结果"或"求运算项"
  - [ ] 多选题型时显示题型分配滑块

- [ ] **Step 3 - 高级设置**
  - [ ] 默认收起高级设置
  - [ ] 点击标题可以展开/折叠
  - [ ] 难度按钮可以切换（简单/中等/困难）
  - [ ] 答案模式下拉框可以切换
  - [ ] 显示配置摘要（年级/题型/数量/难度）
  - [ ] 点击"生成 XX 题"可以生成题目

- [ ] **导航**
  - [ ] 可以返回上一步
  - [ ] 可以前进到下一步
  - [ ] 上一步按钮在 Step 1 不可见

### 2. Toast 通知

- [ ] **生成题目**
  - [ ] 点击"生成题目"显示"正在生成题目..."
  - [ ] 生成完成后显示"已生成 XX 题，耗时 X.Xs"
  - [ ] Toast 3秒后自动消失
  - [ ] 点击 Toast 可以手动关闭

- [ ] **导出 PDF**
  - [ ] 点击"导出 PDF"显示"正在导出 PDF..."
  - [ ] 导出成功显示"PDF 已保存"
  - [ ] 导出失败时降级为图片并提示

- [ ] **下载图片**
  - [ ] 点击"下载图片"显示"正在生成图片..."
  - [ ] 下载成功显示"图片已下载"
  - [ ] 下载失败显示错误提示

- [ ] **删除历史**
  - [ ] 点击删除按钮弹出确认对话框
  - [ ] 确认删除后显示"删除成功"
  - [ ] 取消删除不删除记录

### 3. 一键重生成

- [ ] **首次生成后**
  - [ ] 刷新页面显示"已恢复上次配置"提示条
  - [ ] 提示条显示配置摘要（年级/数量/难度）

- [ ] **配置持久化**
  - [ ] 刷新页面后配置保持不变
  - [ ] 重新打开浏览器配置仍然保存

### 4. 视图切换
