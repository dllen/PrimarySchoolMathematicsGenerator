## 🐛 问题排查

### 问题 1: 预设卡片点击无反应

**可能原因**:
- Vue 组件未正确注册
- 事件未绑定

**排查步骤**:
1. 打开浏览器 DevTools → Console
2. 查看是否有 Vue 警告
3. 检查 Network 标签是否有 404

### 问题 2: 自定义预设不显示

**可能原因**:
- localStorage 被清空
- 获取函数未正确实现

**排查步骤**:
1. DevTools → Application → Local Storage
2. 查看 `math-generator-custom-presets` 是否存在
3. 检查值是否为有效 JSON

### 问题 3: 管理器无法关闭

**可能原因**:
- 点击遮罩层事件未绑定

**排查步骤**:
1. 点击遮罩层（对话框外部）
2. 查看是否有错误
3. 点击右上角 × 按钮
