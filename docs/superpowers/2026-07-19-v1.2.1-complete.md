## ✅ 新增功能

### 1. 预设导入/导出

#### 导出预设 📥
- 一键导出所有自定义预设为 JSON 文件
- 文件名格式：`math-presets-YYYY-MM-DD.json`
- 包含完整的预设数据（名称、描述、图标、配置）
- 导出成功 Toast 提示

#### 导入预设 📤
- 从 JSON 文件导入预设
- 自动验证 JSON 格式
- 跳过无效预设
- 生成唯一 ID 避免冲突
- 导入成功 Toast 提示（导入数量 + 总数）
- 支持重复导入同一文件

#### 错误处理
- JSON 格式错误 → 友好提示
- 非数组格式 → 格式错误提示
- 空数组 → 没有有效预设提示
- 文件读取失败 → 失败提示

---

### 2. 拖拽排序

#### 实现特性
- **HTML5 Drag & Drop API**
- 拖拽手柄（⋮⋮）提升可发现性
- 拖拽时半透明效果
- 松开后自动保存
- 成功/失败 Toast 提示

#### 交互细节
- 鼠标悬停时显示拖拽手柄
- 拖拽开始 → opacity: 0.5
- 拖拽结束 → opacity: 1
- 放置时自动更新 localStorage
- 列表自动刷新

## 📊 技术实现

### API 设计

```javascript
// 导出
exportCustomPresets()
// → { success: true, count: 2 }

// 导入
importCustomPresets(jsonString, { merge: false })
// → { success: true, imported: 2, total: 5 }

// 文件导入
importPresetsFromFile(file)
// → Promise<{ success: true, imported: 2, total: 5 }>

// 拖拽排序
movePreset(fromIndex, toIndex)
// → true (成功) / false (失败)
```

### 数据流程

```
导出: localStorage → JSON → Blob → 下载文件
导入: 文件 → FileReader → JSON.parse → 验证 → localStorage
排序: dragstart (记录 index) → drop (计算位置) → movePreset → localStorage
```

### 唯一 ID 生成

```javascript
// 导入时生成新 ID，避免冲突
id: `custom-${Date.now()}-${Math.random().toString(36).slice(2, 7)}`
```

## 🎓 技术亮点

### 1. Blob API 文件导出

```javascript
const blob = new Blob([json], { type: 'application/json' });
const url = URL.createObjectURL(blob);
// ... 触发下载
URL.revokeObjectURL(url); // 及时释放
```

### 2. FileReader 异步读取

```javascript
const reader = new FileReader();
reader.onload = (e) => { /* 处理 */ };
reader.onerror = () => { /* 错误 */ };
reader.readAsText(file);
```

### 3. HTML5 Drag & Drop

```javascript
@dragstart="handleDragStart($event, index)"
@dragover.prevent
@drop="handleDrop($event, index)"
@dragend="handleDragEnd"
```

### 4. 错误边界

```javascript
try {
  const data = JSON.parse(json);
  // 验证...
} catch (err) {
  return { success: false, error: `导入失败：${err.message}` };
}
```
